# Prompt: Meta Performance Analysis

Analyze the supplied Meta Ads data using TRA's defined success metrics.

Return:
1. The five most important findings.
2. What changed versus the comparison period.
3. Which campaigns, ad sets, or creatives need attention.
4. Which creatives appear worth testing further.
5. Any recommendation that depends on incomplete data, clearly labeled as a recommendation rather than a fact.

Keep the answer short and decision-focused.
