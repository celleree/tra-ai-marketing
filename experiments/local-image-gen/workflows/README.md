# Workflows

Store exported ComfyUI workflow JSON files here once a workflow is worth reproducing or comparing.

For each workflow, record enough context to identify:

- model/checkpoint used;
- required custom nodes;
- intended TRA test case;
- important settings not obvious from the JSON;
- whether the workflow is current, experimental, or retired.

Do not commit model weights, generated outputs, private TRA media, or caches.
