# TRA Knowledge Base

This folder contains the source material the AI uses when producing copy, creative briefs, and analysis.

## Current Sources

- `creative-formats.md` - approved creative-format reference.
- `raw-customer-reviews.md` - canonical raw English review source from the `TRA Five-Star Reviews` Google Sheet. Includes reviewer names and full review text. Spanish reviews are intentionally excluded.
- `customer-insights-from-reviews.md` - derived customer problems, objections, desired outcomes, proof themes, personas, and voice-of-customer insights based on the supplied review set.

When review language or customer evidence is needed, read `raw-customer-reviews.md` first for the original source and use `customer-insights-from-reviews.md` for summarized patterns.
